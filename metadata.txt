description=This plugin enables users to customize the background colors of layers and groups in the layer tree view, enhancing visual organization and project management. 
about=It streamlines the organization and management of complex QGIS projects by allowing users to visually distinguish different layers or groups through custom background colors. This plugin adds a menu called "Layer Highlight Color", located above the "Properties" in the "Layer Properties" menu. Always choose pastel or lighter colors. The code implements "WCAG 2.0" contrast ratio checking to avoid colors that can make hard to read the layer text.

changelog=

 Version 0.8:
 * New: optional wrapping of long layer, group and symbology names over several lines, with rows growing only where needed and re-wrapping when the panel is resized.
 * Names break at their own separators (_ - . /) rather than mid-word; a name with no separators falls back to breaking anywhere.
 * Toggle in "Plugins > Layer Color Plugin > Wrap Long Layer Names" and in the layer context menu; the choice is remembered between sessions.
 * Fixes a horizontal scroll bar in the Layers panel: row widths no longer ignore the tree indentation (applies with wrapping on or off).
 * Status icons are capped to one line's height so they are not scaled up on wrapped rows.

 Version 0.7:
 * Disabling/reloading the plugin no longer deletes highlight colors from the open project.
 * On unload, QGIS's original layer tree delegate (layer indicator icons) and right-click menu are restored.
 * Context menu insertion skips null/invalid actions (QGIS 4 / Qt6 robustness).

 Version 0.6:
 * Qt6 / QGIS 4 compatibility: imports via qgis.PyQt, fully scoped enums, exec() instead of exec_(), QAction import for Qt5 and Qt6.
 * Guard against layers without a data provider when drawing indicator icons.

 Version 0.4:
 * Highlight colors are now applied to specific layers or groups (previously all layers or groups with the same name had the same highlight color applied).

   (changes by Alexander Hajnal – github.com/Alex-Kent)

 Version 0.3:
 * Fixes a minor issue where, under certain conditions, a layer does not retain its color after the project is closed if the color change is made while it is inside a group.

 Version 0.2:
 * Fixes a mall cosmetic issue where the plugin was replacing the standard QGIS icon at the top of application windows and panels.
